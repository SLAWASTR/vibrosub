# 🔊 VibroSub — Тактильный Аудио-Сабвуфер для Google Pixel 8 Pro

> **Превратите ваш Google Pixel 8 Pro в портативный вибро-сабвуфер!** Приложение анализирует музыку в реальном времени с помощью FFT-спектрограммы и передает низкие частоты (бас, бочку 808, саб-бас) напрямую в высокоточный вибромотор смартфона с динамической силой и амплитудой.

---

## ⚡ Особенности и использование возможностей Pixel 8 Pro на 100%

Pixel 8 Pro оснащен одним из лучших в мире тактильных приводов — **Cirrus Logic High-Definition Linear Resonant Actuator (LRA)** с откликом менее 5 мс и поддержкой расширенных примитивов Android 14+.

В **VibroSub** задействованы все передовые API Android:
1. **Аппаратные тактильные примитивы (`VibrationEffect.Composition`)**:
   - `PRIMITIVE_THUD` — используется для воспроизведения глубокого физического удара бас-бочки (Kick Drum / 808 Sub) с регулируемой силой.
   - `PRIMITIVE_CLICK` и `PRIMITIVE_LOW_TICK` — для четких транзиентов малого барабана (Snare) и перкуссии.
   - `PRIMITIVE_SPIN`, `PRIMITIVE_QUICK_RISE`, `PRIMITIVE_QUICK_FALL` — для нарастающих электронных дропов.
2. **256 уровней амплитудной модуляции (`hasAmplitudeControl`)**:
   - Вибрация не просто включается/выключается, а плавно повторяет форму огибающей басовой волны трека.
3. **Медиа-канал вибрации (`VibrationAttributes.USAGE_MEDIA`)**:
   - Гарантирует максимальный приоритет тактильного потока без подавления системными фильтрами звонков.
4. **Адаптивный FFT-детектор транзиентов (Peak Onset Detection)**:
   - В отличие от примитивных плееров, телефон не "гудит сплошным монотонным зумом". Специальный алгоритм отслеживает динамический порог громкости и выделяет четкие физические удары ритма.
5. **Поддержка Google AudioFX HapticGenerator DSP**:
   - Встроенный в Android 12+ алгоритм аппаратного связывания звука и тактильности.
6. **Встроенный генератор 808 Демо-бита**:
   - Позволяет мгновенно протестировать виброотдачу без необходимости сразу искать аудиофайлы на устройстве.

## 📱 Как установить и запустить на Pixel 8 Pro

1. Распакуйте скачанный zip и перекиньте файл `VibroSub-Pixel8Pro-Release.apk` на ваш телефон (через Telegram, Google Drive, Quick Share или USB-кабель).
2. Нажмите на APK в телефоне и выберите **Установить** (если потребуется, разрешите "Установку из неизвестных источников").
3. При первом запуске приложение попросит разрешение:
   - **Запись аудио (Record Audio)** — *Обязательное системное требование Android для работы `Visualizer`*. Микрофон не используется и звук не записывается; разрешение необходимо операционной системе для считывания частотного спектра воспроизводимой музыки.
4. Нажмите **"808 Демо-бит"** или **"Выбрать трек"** для открытия любого вашего MP3/FLAC/WAV файла.
5. Держите Pixel 8 Pro в руке и почувствуйте сабвуферный удар!

## 🎛️ Экраны приложения

### 1. Плеер и Визуализатор Сабвуфера
- **Анимированный сабвуфер**: диффузор физически пульсирует и раскачивается синхронно с вибрацией в руке, а радиальные кольца отображают акустические ударные волны.
- **16-полосный эквалайзер спектра**: наглядно показывает частоты Sub-Bass, Mid и Treble.
- **Быстрый ползунок силы вибрации**: регулировка от 0% до 200% MAX прямо на главном экране.

### 2. Вибро-Тюнинг (Haptic Studio)
- **Pixel Sub-Woofer**: гибридный режим — глубокий гул низких частот + мощный импульс удара бочки (`PRIMITIVE_THUD`).
- **Динамический бит (Beat Punch)**: акцент на четких ударах ритм-секции.
- **Непрерывная волна баса**: непрерывная аналоговая модуляция силы вибрации.
- **Google DSP HapticGenerator**: аппаратный движок Google.
- **Тонкая настройка**:
  - Сила удара бочки (0–150%)
  - Четкость щелчка снейра (0–150%)
  - Рокот суб-баса (0–150%)
  - Фильтр среза низких частот: 60Hz, 100Hz, 120Hz, 180Hz, 250Hz.
  - Шумоподавляющий порог (Noise Gate).

### 3. Тест Pixel 8 Pro (Hardware Benchmark)
- Полная проверка аппаратных возможностей вибромотора:
  - Модель чипа вибромотора (Cirrus Logic LRA).
  - Наличие 256-уровневого регулятора амплитуды.
  - Индикаторы поддержки примитивов Android 14 (`THUD`, `CLICK`, `LOW_TICK`, `SPIN`, `QUICK_RISE`, `QUICK_FALL`).
- **Интерактивный тестовый пад**: кнопки для моментального одиночного воспроизведения каждого эффекта.
